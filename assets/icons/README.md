# App Icons

Place your application icons here:

| File | Size | Use |
|------|------|-----|
| `icon.png` | 512×512 | Linux / AppImage |
| `icon.ico` | 256×256 | Windows .exe |
| `icon.icns` | 512×512 | macOS .app |

The default ⬡ hex logo works as a placeholder.
`electron-builder` reads icons from this folder automatically via `electron-builder.yml`.
