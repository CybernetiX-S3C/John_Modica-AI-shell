# ─── requirements-tts.txt ─────────────────────────────────────────────────────
# John Modica AI Shell — Local TTS Server Dependencies
#
# Install:   pip install -r requirements-tts.txt
# Python:    3.9 – 3.11 recommended  (3.12 may have torch compat issues)
# GPU:       NVIDIA CUDA optional — CPU works fine, slightly slower synthesis
#
# DISK SPACE:
#   These packages + XTTS-v2 model = ~4 GB total first time
#   Model cached at: ~/.local/share/tts/  (never in repo)
#   Packages cached at: pip cache (~2 GB)
#
# WHAT EACH DOES:
#   TTS          — Coqui Text-to-Speech (XTTS-v2 engine, voice cloning)
#   torch        — PyTorch (XTTS-v2 neural network runtime)
#   torchaudio   — Audio processing for PyTorch
#   numpy        — Array math (audio sample processing)
#   soundfile    — WAV read/write
#   librosa      — Audio analysis (VAD, resampling)
#   flask        — HTTP server wrapper (used if switching from stdlib http.server)
# ─────────────────────────────────────────────────────────────────────────────

# ── Core TTS engine ───────────────────────────────────────────────────────────

#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
